# Project overview



### Scenario

Pawsitive Pet Academy, founded by Sarah Smith in 2023 and based in Durban, provides pet-care education and practical animal-training opportunities.

## Intended users

Pet owners, families, pet sitters, kennel staff, veterinary assistants, aspiring entrepreneurs and animal lovers.

#### 

#### Proposed system requirements

* View academy information.
* Browse courses and course details.
* View fees and course content.
* Select one or more courses.
* Calculate discounts automatically.
* Request information.
* Request a quotation.
* Access contact information.
* Maintain a consistent website and mobile experience.
