# Individual final report checklist

- [ ] Use the official IIE assignment template.
- [ ] Include all Task 1 individual and group work required.
- [ ] Include all Task 2 information and links.
- [ ] Include Task 3 website development evidence.
- [ ] Include Figma link.
- [ ] Include website repository and published website links.
- [ ] Include mobile application repository link.
- [ ] Include YouTube Unlisted video link.
- [ ] Include PowerPoint presentation in GitHub repository.
- [ ] Include update log and WIL Coordinator feedback.
- [ ] Highlight updates throughout the report.
- [ ] Include completed Annexure A: Declaration of Authenticity.
- [ ] Include completed Annexure B peer evaluation forms.
- [ ] Ensure individual sections and annexures are your own.
- [ ] Check that all links work before submission.

Use the official Annexure A and Annexure B forms supplied by your institution. They are not recreated here.
