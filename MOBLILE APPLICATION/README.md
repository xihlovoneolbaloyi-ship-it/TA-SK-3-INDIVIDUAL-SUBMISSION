# Pawsitive Pet Academy mobile application

This is an Expo / React Native starter demonstrating the same brand and key user journey as the website.

## Setup
1. Install Node.js LTS.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npx expo start`.
5. Scan the QR code with Expo Go, or run on an emulator.

The mobile app currently demonstrates Home, Courses, course selection, discount calculation and a quote-request form. The quote form is front-end only. It does not submit information to a server.
